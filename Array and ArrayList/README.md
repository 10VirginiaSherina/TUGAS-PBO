# Array and ArrayList
This projects is a simple bank account management program developed using Java. It demonstrates the application of Object-Oriented Programming (OOP) concepts, including classes, objects, encapsulation, and object relationships. 
The program uses an **ArrayList** to store and manage multiple customer objects. 

## 📂 Code Structure
- **Account.java** : Manages the account balance and provides deposit and withdrawal methods.
- **Customer.java** : Stores customer information and links each customers to an _Account_ object.
- **MyBank.java** : Contains the _main()_ method, manages customers using an ArrayList, and displays their account information

## ⛓️ How to Run
1. Compile:
```bash
javac Account.java Customer.java MyBank.java
```
2. Execute:
```bash
java MyBank
```
